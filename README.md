# Prathima Hospitals V6 — GitHub Pages Ready

This is the consolidated V6 static website package for GitHub Pages.

## Root structure
- `index.html` is at the repository root.
- `assets/` contains CSS, JavaScript, icons, doctor images, hero images, facility images and location images.
- `about-us/`, `contact-us/`, and `specialities/` contain their page folders.
- `.nojekyll` is included.

## GitHub Pages
Upload the CONTENTS of this folder directly into the repository root. Do not upload the ZIP as a single file and do not create an extra nesting folder around the site.

## Included approved homepage changes
- Refined hero/header and mobile hero treatment.
- User-provided call, emergency siren and appointment calendar icons.
- Recognizable specialty SVG icons and specialty presentation.
- Larger typography and reduced excessive whitespace.
- 10 doctor profiles with supplied images, including Dr. Yadati Santosh Deepthi.
- Doctor-card hover lift and rotating theme glow.
- Supplied Kukatpally and Kachiguda location images.
- Supplied Standard Room and Suite Room images.
- Why Prathima six-card section; Care at Prathima removed.
- Cardiology-only homepage pathway section removed.
- Repetitive hero-adjacent specialty/benefit rows removed.
- Mobile hamburger menu fix retained.

## GitHub-only compatibility
Netlify `_headers` and `_redirects` are retained as reference but are not processed by GitHub Pages. Equivalent simple HTML redirect pages are included under the temporary non-Cardiology specialty paths so those links do not become GitHub 404 pages.
